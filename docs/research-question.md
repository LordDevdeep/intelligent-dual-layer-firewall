# Research Question

## Primary Research Question

Can validated attack intelligence learned from suspicious traffic
and honeypot behaviour improve the response of a second defensive
layer against subsequent similar attacks?

## Research Objective

The project aims to investigate whether behavioural information
collected from suspicious network activity can be converted into
validated attack intelligence and used to improve the defensive
response of a second firewall layer.

## Hypothesis

A dual-layer firewall architecture that uses validated attack
intelligence from previous observations will provide a faster or
more effective response to subsequent similar attacks compared with
a static defensive configuration.

## Key Comparison

Static Defense vs Adaptive Defense

The comparison will consider:

- Detection rate
- Precision
- Recall
- F1-score
- False-positive rate
- Detection time
- Response time
