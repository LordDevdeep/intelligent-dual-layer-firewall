# Research Methodology

## Development Approach

The system will be developed incrementally in the following stages:

1. Build an isolated virtual cybersecurity laboratory.
2. Implement the first firewall layer.
3. Deploy a single isolated honeypot.
4. Implement machine-learning-based suspicious traffic detection.
5. Generate attack intelligence from firewall and honeypot data.
6. Validate the generated intelligence.
7. Implement adaptive policies in the second firewall.
8. Conduct controlled repeated-attack experiments.
9. Compare static and adaptive defense performance.

## Experimental Principle

All cybersecurity experiments will be performed inside an isolated
virtual environment using controlled test traffic.

## Evaluation

The adaptive system will be compared with a baseline static-defense
configuration using measurable security and performance metrics.
